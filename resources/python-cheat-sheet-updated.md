### Variables

```python
name = "Techtonz"
year = 2026
is_learning = True
```

### Lists & loops

```python
topics = ["python", "sql", "pandas"]
for t in topics:
    print(t)
```

### Functions

```python
def greet(name):
    return f"Welcome, {name}!"

print(greet("Ada"))
```

### Dictionaries

```python
user = {"name": "Ada", "track": "data"}
print(user["track"])
```
