## Quick preview (web version)

### Filter and sort

```sql
SELECT user_id, country, plan
FROM users
WHERE country = 'NG'
ORDER BY user_id
LIMIT 20;
```

### Aggregate by group

```sql
SELECT country, COUNT(*) AS users
FROM users
GROUP BY country
ORDER BY users DESC;
```

### Join users and orders

```sql
SELECT u.user_id, u.country, o.amount
FROM users AS u
INNER JOIN orders AS o
  ON u.user_id = o.user_id;
```

### Repeat customers

```sql
SELECT user_id, COUNT(*) AS orders
FROM orders
GROUP BY user_id
HAVING COUNT(*) >= 2;
```
